# DECISIONS — 중요한 설계 결정의 당시 기록 (양식)

| ID | 결정 시점/마일스톤 | 결정할 질문 | 확인된 제약/출처 | 대안·언제 바뀌는가 | 사용자 선택/임시 결정 | 사용자가 쓴 이유(원문) | 에이전트 보충·한계 | 빠른 검증 계획 | 근거 상태 |
|---|---|---|---|---|---|---|---|---|---|

상태: `TASK_SPECIFIED / OBSERVED / ASSUMED / UNKNOWN`. 과거에 기록되지 않은 결정 이유를 사후에 발명하지 않는다. 새로운 검토는 새로운 평가로 기록한다.
