# 검증된 Mermaid 다이어그램 (선택형)

- 중요한 기능이 실제로 통합된 후 `docs/diagrams/architecture.mmd`, `feature-flow.mmd`를 생성합니다.
- 파일·함수 간 의존 관계와 **실제로 확인한 런타임 흐름**을 구분합니다.
- 한국어로 읽히는 라벨을 사용하되 실제 함수·파일 식별자는 원문 그대로 유지합니다.
- 코드 근거가 없는 관계는 `INFERRED` 또는 `PLANNED`로 표시합니다.

```mermaid
flowchart LR
    A[사용자 입력] --> B[실제 진입 함수]
    B --> C[핵심 처리]
    C --> D[검증된 출력]
```

> 위 그림은 템플릿 예시이며, 시험 과제의 실제 구현을 나타내지 않습니다.
